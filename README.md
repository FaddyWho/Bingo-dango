# [Project Name] – Shared Folder

Human setup guide. AIs should read `00_start-here.md` instead.

## Set up GitHub (Shruti, once)
1. Create a **private** repository named `[project-name]-research`.
2. Upload everything from this folder (drag and drop in the browser works).
3. Settings → Collaborators → add Anna, Khushboo, Fahad, Amber with write access.
4. Copy the repo link into `00_start-here.md` (the "Link" line) and into the Miro "Shared folder plan" board.

## How to edit (no Git knowledge needed)
1. Open the file on GitHub → click the pencil icon → edit → **Commit changes**.
2. Commit message format: `[file] Name: what changed`, e.g. `[05_concepts] Fahad: add C02 idea`.
3. Edit the top of a file only if you are its lead. Everyone else: add notes under `## Suggestions`.
4. Uploading files: Add file → Upload files, into the right folder.

## Getting files to your AI
- If your AI can read GitHub links, give it the link to `00_start-here.md`.
- If not, open the file on GitHub → click **Raw** → copy → paste into the AI. Or upload the .md file.
- Every chat starts with: **"Read 00_start-here.md and follow it."**
- When the AI writes something, copy it into the right file on GitHub. AIs can't save to GitHub for you unless a GitHub connection is set up.
